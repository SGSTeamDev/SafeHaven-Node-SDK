# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.0.5] - 2026-11-19

### Changed

- Bound and redact provider error diagnostics while preserving actionable Safe Haven status and request information.
- Stage npm releases for maintainer approval instead of publishing directly from CI.

### Security

- Updated vulnerable transitive dependencies and added repository secret checks.

## [1.0.0] - 2025-03-04

### Added

- Authentication
- Accounts
- Verification
- Transfers

## [1.0.1] - 2025-05-08

### Added

- Automatic token refresh

### Fixed

- Token expiry

## [1.0.3] - 2026-01-22

### Added

- Virtual account

## [1.0.4] - 2026-11-19

### Added

- Explicit OTP-required and vID bypass modes for sub-account creation.

### Changed

- Preserve Safe Haven provider response details on SDK errors.
